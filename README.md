# project-handoff · 项目交接

> 让一个 agent 把项目“无缝交接”给下一个 agent——哪怕是换到不同工具。

## 一句话

在项目上工作了很久的 agent（可能是 WorkBuddy、Claude Code、Cursor 中的任何一个），要转交给下一个 agent 时，用本 skill 生成一份**分层交接包**，让下一个 agent 快速接手、尽量还原上一个 agent 的能力，并且**省 token、速度快、信息完整**。

## 解决什么痛点

换 agent 接手同一个项目，最常见的三个坑：

1. **上下文丢了**——上一个 agent 脑子里知道的“为什么这么设计、卡在哪、还剩什么没做”，换个人就没了。
2. **上手太慢**——新 agent 要么把整个项目读一遍（费 token），要么抓瞎。
3. **接手就跑偏**——新 agent 对着任务清单字面瞎做，偏离了项目的真实目标。

本 skill 用“分层交接包 + 活档案”来解决，核心原则：**分层按需加载，索引不搬原文，首次全量 + 之后增量维护**。

## 实测：它到底管不管用？

用 3 组对照实验验证过（2 个小游戏 + 1 个真实中型项目 YutoDo）：同一个项目、同一份任务，分别用「**直接交接 / 简单文档 / 本 skill 交接包**」交给下一个 agent，对比结果。

| 能力 | 直接交接 | 简单文档 | 本 skill |
|---|---|---|---|
| 守住用户明确拒绝的功能（不跑偏） | 跑偏 | 可能跑偏 | ✅ |
| 直达已知 bug 的根因（免重复排查） | ❌ | ❌ | ✅ |
| 传递“隐性规范”（代码里看不出的约定） | ❌ | ❌ | ✅ |
| 结果可复现，不靠接手者的经验与运气 | ❌ | ❌ | ✅ |

**最有说服力的一条是“隐性规范”的传递。** 以真实项目 YutoDo 为例：它的 i18n 是**编译期强制**的——加一句中文文案就必须同时补英文，否则直接编译失败。这条规矩，项目自带的文档里没写，**只有本 skill 生成的交接包会把它明确记下来**。没有交接包时，接手的 agent 加一句话就会编译失败、返工；有交接包则一次通过。

在 YutoDo 实测中，三种方式的改动都通过了 `npm test`（637/637）与类型检查 —— **区别不在“这一次能不能做对”，而在“换个人、换个任务，还能不能稳定做对”。**

### 什么时候最值

- ✅ **中大型项目 + 复杂任务 + 一堆“不成文的规矩”** —— 收益最大，直接避免翻车与返工
- ✅ **需要换 agent / 换工具接力的长项目** —— 让每一次接手都站在同一起跑线，接手者不再靠经验和运气
- ⚖️ **小脚本、一次性任务** —— 项目里已有的 README / CLAUDE.md 通常就够了，不必生成交接包

一句话：**它带来的不是“省一半 token”，而是“换个人接手也不翻车”。**

## 交接包长什么样

生成在目标项目根目录下，全部是纯文本，任何 agent 都能读：

```
<项目根>/
├── .handoff/
│   ├── HANDOFF.md      入口卡（唯一必读，几百字，含给新 agent 的接手指令）
│   ├── status.md       状态快照（进度、未完成任务七要素、下一步）
│   ├── decisions.md    决策、约定与禁忌、踩过的坑
│   ├── capabilities.md 项目命令与工作流
│   └── index.md        关键文件索引（只记路径，不搬原文）
└── AGENTS.md / CLAUDE.md / .cursorrules   入口跳板（按目标工具）
```

## 怎么用

**交接（你要交出的那一个）**：说「准备交接项目 / 生成交接包 / handoff」，它会扫描项目 + 结合你的会话上下文，生成 `.handoff/` 五件套和入口跳板，最后给你一段“开场提示词”直接发给新 agent。

**接手（你刚来的那一个）**：说「接手项目 / 继续这个项目 / onboard」，它会先读入口卡 → 按需深入 → 理解自检 → 向你复述现状和下一步，**等你确认再动手**。

## 安装

- **WorkBuddy**：从 SkillHub 搜索“项目交接 / project-handoff”安装，或手动复制本目录到 `~/.workbuddy/skills/project-handoff/`。
- **Claude Code / Cursor 等**：本 skill 生成的交接包是纯文本，任何 agent 都能直接读（入口卡里自带接手指令），不要求对方也装本 skill。

## 跨工具说明

交接包（`.handoff/` + 入口跳板）是工具无关的。入口跳板会自动适配：Claude Code 用 `CLAUDE.md`、Cursor 用 `.cursorrules`、其他用 `AGENTS.md`，确保新 agent 不用你手动提示就能自己发现交接包。
